# Launch copy — local review draft

**Headline:** One script. Many ways to tell it.

**Short description:** KinoDraw turns scripts into locally rendered videos with
editable storyboards, narration and captions. Start with a story, explainer,
product concept, lesson or explicitly fictional data story. Scientific scenes
plot supplied observations or a bounded analytical model with source notes.

**Demo caption:** Explore five source-backed use cases. Download the script,
caption file and project ZIP to inspect the work behind each packaged video.
The gallery manifest records the actual file hashes and media decode checks.

**Science caption:** A NOAA annual CO₂ series and an ideal harmonic oscillator
show two distinct origins for a plot: retained observations and a stated equation.
Their units, citations, transforms and limitations are saved with the examples.

**Developer invitation:** Build from the source examples, inspect the storyboard,
and render locally. Use the offline developer surface for confined previews;
opt into narrated MCP movies with cached local voice models or measured cached
narration. Full pipeline setup may download local voice/search dependencies.

This is factual copy for review. It does not claim universal competitor
superiority, production Classroom deployment, a Chrome Web Store listing, or
publication of the local gallery. Package integrity is separate from artistic,
scientific and factual review. The product launch and transport-news scripts are
fictional; do not present their signup invitation or survey figures as real.
