# Doodle Studio for Classroom: architecture and module contracts

A Manifest V3 Chrome extension for elementary-school teachers. A teacher opens one of their
Google Classroom classes, clicks **Make a video**, gives a script (file or pasted text), and the
extension makes the hand-drawn video **inside Chrome** and posts it to that class's Classwork.
Only teachers can use it. The only AI model it calls is GPT-6 Luna, through Doodle Cloud.

The Python app (`kinodraw/`) stays the source of truth for the rules. `extension/engine/` is
a faithful English-only port, and `tests/` hold it to the Python output (parity fixtures).

```
classroom.google.com ── content/classroom.js (a "Make a video" button, shown only to the class's teachers)
        │  chrome.runtime.sendMessage
        ▼
sw.js (service worker) ── teacher-status checks, opens the studio tab
        ▼
studio/studio.html (extension tab: sign-in, teacher gate, script, progress, preview, posting)
   ├── engine/      script → storyboard (rules + Luna) → timeline → pacing → frames      (port of kinodraw/)
   ├── media/       HeadTTS/Kokoro voice (worker) · narration + music mix · WebCodecs → MP4 (Mediabunny)
   └── google/      OAuth (launchWebAuthFlow) · Classroom API · Drive resumable upload · Doodle Cloud client
Doodle Cloud (Cloudflare Worker, ~/test/doodle-cloud): POST /v1/edu/session (Google token → teacher check →
   Doodle Cloud token on the Luna-only "edu" plan), then the usual /v1/videos and /v1/direct.
```

## Rules of the road

- **No remote code.** Every JS/WASM file is in the package. `extension_pages` CSP is
  `script-src 'self' 'wasm-unsafe-eval'` so no `blob:`/`data:` workers, no inline scripts, no `eval`.
  Model weights and voices are *data* and may be downloaded (Hugging Face, pinned, cached).
- **Import the vendored libraries by path**: `../vendor/transformers/transformers.min.js`,
  `../vendor/mediabunny/mediabunny.min.mjs`. The voice worker (`media/tts-worker.js`) runs HeadTTS's own
  worker module (`../vendor/headtts/modules/worker-tts.mjs`); HeadTTS's page-side class is not used (it
  needs a `blob:` worker and only notices a failed load by timing out). Point ORT at the bundled wasm:
  `env.backends.onnx.wasm.wasmPaths = chrome.runtime.getURL('vendor/transformers/')` (in a worker:
  `new URL('../vendor/transformers/', import.meta.url).href`).
- **Tests never need a real Google account.** `CONFIG.dev` is false in the source; the e2e harness
  copies the extension and flips it, which enables only `chrome.storage.session['devToken']` in auth.
- English only (US). Everything a teacher sees is plain, friendly language.

## Contracts

### media/tts.js
```js
export async function createVoice({ voice = CONFIG.voice.voice, onStatus, signal }) // → Voice
// onStatus({ stage: 'download'|'load'|'ready', loaded, total, backend: 'webgpu'|'wasm' }); an aborted
// signal stops the download (AbortError). WebGPU (fp32 model) first; on a WebGPU failure, WASM with the
// same, already-downloaded model; without WebGPU, WASM with the smaller q8 model. Every voice file comes
// from CONFIG.voice.revision.
voice.synthesize(spoken)   // → Promise<{ pcm: Float32Array (mono), sampleRate: 24000, duration: seconds,
                           //              charTimes: number[] }>   charTimes[i] = seconds from clip start when
                           //   character i of `spoken` is heard; non-decreasing; length === spoken.length
voice.close()
```
`spoken` never contains digits (numbers are already words). Same alignment idea as `kinodraw/voice.py`:
clause marks anchor clauses, letters inside a word share its timing proportionally.

### media/encode.js
```js
export async function createEncoder({ width = 1920, height = 1080, fps = 30, videoBitrate = 3_000_000,
                                      sampleRate = 48000, onProgress })  // → Encoder
encoder.codecs                  // { video: 'avc1.…', audio: 'aac' | 'opus' }
await encoder.addFrame(canvas)  // HTMLCanvasElement or OffscreenCanvas; frame k is at k / fps
await encoder.addAudio(left, right)   // whole soundtrack once
const blob = await encoder.finish()   // video/mp4 (H.264 + AAC; Opus only if no AAC encoder at all)
```
