# Bundled sound effects

Every file here is CC0 1.0 (a public-domain dedication), so no attribution is required. The packs are listed so
each file can be traced to its source. Each file is named after the cue kind it plays for (`<kind>_<n>.wav`).
The files were converted to 48 kHz mono 16-bit WAV, trimmed to start just before their loudest moment, capped
in length and peak-normalized; nothing else was changed. The app also synthesizes its own variants of every kind
(`kinodraw/audio/sfx.py`), so the sound effects still work without these files.
